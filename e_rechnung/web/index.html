    E-Rechnung öffnen

    XRechnung (XML) oder ZUGFeRD / Factur-X (PDF) hierher ziehen oder

    Anbindung an die Firmen-KI

    Die KI erzeugt die Rechnungsdaten als JSON (Schema: /api/schema) und ruft eine dieser Schnittstellen auf. Fehlen Pflichtangaben, kommt eine Liste mit Feldnamen und deutscher Erklärung zurück, die die KI direkt beheben kann.

    HTTP-API

    POST /api/erstellen?format=xrechnung-cii   Rechnungs-JSON  →  Datei (oder 422 mit "issues")
POST /api/pruefen?format=xrechnung-cii     Rechnungs-JSON  →  {"ok", "issues", "totals"}
POST /api/lesen                            XML oder PDF    →  {"data", "issues"}
POST /api/anzeigen                         XML oder PDF    →  HTML-Ansicht
POST /api/umwandeln?format=zugferd         XML oder PDF    →  Datei
POST /api/offiziell                        XML oder PDF    →  {"valid", "messages"}
GET  /api/schema · /api/tools · /api/beispiel · /api/formate
    curl -X POST "http://127.0.0.1:8765/api/erstellen?format=zugferd" \
     -H "Content-Type: application/json" --data @rechnung.json -o rechnung.pdf

    Function Calling (Claude, OpenAI …)

    Fertige Werkzeug-Definitionen: /api/tools (e_rechnung_erstellen, e_rechnung_pruefen, e_rechnung_lesen).
